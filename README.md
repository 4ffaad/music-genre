# AI Music Genre Classification & Clustering Project

This project involves building machine learning models to classify music genres and perform clustering on a dataset. The project leverages supervised learning techniques and clustering algorithms, with a focus on classification accuracy and clustering results.

## Project Overview

The project uses a dataset of music tracks to predict the genre of each song and to group similar songs based on numerical features using K-means clustering. The project also includes data preprocessing (such as handling missing values and scaling) and evaluation of model performance through confusion matrices.

## Key Features

- **Supervised Learning**: Trained and compared multiple models, including Support Vector Machine (SVM) and Random Forest, to predict the music genre.
- **Model Evaluation**: Used confusion matrices for multi-class classification tasks to evaluate model performance.
- **Kaggle Submission**: Generated predictions for an external dataset and submitted them to Kaggle as part of a competition.
- **Clustering**: Applied K-means clustering on a dataset with missing values and two numerical features to form meaningful clusters.
